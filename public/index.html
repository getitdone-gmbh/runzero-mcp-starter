MCP server starter

A remote MCP server over Streamable HTTP, ready to deploy on run.zero.

Endpoint

/mcp

Connect

claude mcp add --transport http starter /mcp

Tools

  • starter_text_statsCounts words and sentences of a text and estimates reading time.
  • starter_current_timeReturns the current time in any IANA time zone.
